# Forester project audit
Unity 6000.6.2f1, URP 17.6.0, Input System 1.20.0, Unity Test Framework 1.8.0. Newtonsoft is already installed. No pipeline conversion or package upgrade is required.

The factory prototype in Assets/Game is retained as an archived playable prototype. Its authoritative attacking-villager simulation and factory plans do not define Forester. Reuse is limited to the HTTP transport and original visual assets. Forester has independent domain, authoring data, wrappers and scene.

Original Kenney assets include FBX, OBJ and GLB models, PNG previews and textures. The chosen FBX assets are static models; no dedicated water/foam animations, forest hazard effects or matching audio have been identified. Existing project settings and sample scenes are preserved, including pre-existing user modifications. Build commands explicitly select the dedicated scene rather than changing EditorBuildSettings.
